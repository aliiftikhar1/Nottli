# Nottli — Visual Direction

## Mode

Operate: a small utility used repeatedly during focused work.

## Direction

The first slice feels like a premium desk object: warm ink on an oat-paper ground, a single vivid coral accent, and a hand-drawn character that behaves like a quiet studio companion. The utility surface stays crisp and calm so the character can carry personality without turning the app into a toy.

## Palette

- Ink: `#1F2024`
- Muted ink: `#74747C`
- Paper: `#F6F1E9`
- Surface: `#FFFDF9`
- Line: `#E6DED2`
- Coral: `#F06D5A`
- Coral dark: `#C95345`
- Sage: `#C9D8C2`
- Sky: `#D7E7EA`

## Typography

Use `DM Sans` for interface text and `Fraunces` for the short editorial note title. Both load from the local package only when available; system fallbacks preserve layout.

## Signature interaction

The mascot reacts to the note surface: idle when the note is empty, writing while text is present, and happy after save. The note editor is the first-class action, not a modal or a secondary card.

## Materials and motion

Use paper-like flat surfaces, thin warm lines, offset soft shadows, and one authored mascot bob/peek moment. Respect `prefers-reduced-motion`.
